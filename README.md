## Первое правило

Перед первым использованием сделайте в текущем окружении:

```
pip install nbstripout
nbstripout --install
```

Это нужно, чтобы в гит не писался вывод в ipynb'ах. Иначе будут проблемы с конфликтами коммитов.

## Второе правило

Один человек --- один нотебук. За исключением финального, его нужно будет как-то делать особенно.

## Третье правило

Работаем строго в своих в ветках под задачу.

Цикл такой:

```
git switch main
git pull
git switch -c feature/clean-data     # новая ветка под задачу

# работаете, коммитите
git add .
git commit -m "Очистка пропусков в sales.csv"
git push -u origin feature/clean-data
```

После пуша GitHub предложит кнопку `Compare & pull request`. Заполняете описание и выбираете ревьюера (Reviewers справа). Ревьюер оставляет комментарии или нажимает Approve. После одобрения вы жмёте Merge (удобнее всего `Squash and merge`: вся ветка превращается в один коммит) и удаляете ветку. Остальные потом делают `git switch main` && `git pull origin`
